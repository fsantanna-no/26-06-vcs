# Git DAG as a CvRDT

## Context

- Source: external discussion pasted by the user (2026-08-26)
- Claim: the Git object store (commits, trees, blobs) synced via
  `git fetch` is a CvRDT; the file contents are not
- Relevant to main.tex Section "Correspondences with CRDTs" and
  the dVCS/Wiki prototype

## Argument (as pasted)

- `git fetch` merges a remote DAG into the local DAG by graph union
- Union is commutative, associative, idempotent
    - fetch Alice then Bob == fetch Bob then Alice
    - (mine + Alice) + Bob == mine + (Alice + Bob)
    - mine + mine == mine
- Deterministic: content-addressed hashes (SHA-1/SHA-256)
- => Grow-Only Directed Graph CvRDT; states form a join-semilattice
    - state A has X, state B has Y, LUB has both
- Merkle linking: children embed parent hashes, past nodes cannot
  be altered without breaking descendants -> safe as a G-Set
- The catch: two meanings of "data"
    - object store (DAG) converges: strong eventual consistency
    - file tree does NOT converge: divergent heads (branches)
      need a human to merge
- P2P databases keep the Merkle DAG for sync and add CRDT math
  inside the nodes so contents merge too

## Assessment (Claude)

- CONFIRMED in essence: object store == G-Set keyed by hash;
  union merge satisfies the CvRDT laws; SEC on the object DB
- Refinements to state precisely in the paper
    - refs/branches are NOT a CvRDT: mutable pointers, fast-forward
      rules, force-push; `git fetch` converges objects, not heads
    - Freechains fix: no named refs, heads derived from the DAG
      (all tips) -> the whole structure becomes a CvRDT
    - Git GC prunes unreachable objects -> grow-only only for
      reachable objects in practice
    - Merkle DAG is stronger than a plain G-Set: the set is
      causally closed (no child without parents) -> this is what
      EO-Posets (arXiv 2304.04318) formalize
    - split matches main.tex "three layers": DAG sync is
      state-based (CvRDT); payload patches applied in consensus
      order are op-based (CmRDT-like); file contents converge
      only through the consensus order
- Replace the pasted blog/video refs with academic ones
    - Shapiro et al. 2011 `p2p.crdts`: G-Set, join-semilattice,
      SEC definition
    - Kleppmann PaPoC'22 `p2p.byz`: hash graph makes CRDTs BFT;
      "This graph resembles a Git commit history"
    - Kleppmann & Howard 2020 `p2p.dag.sync`: Byzantine causal
      broadcast over hash DAGs
    - EO-Posets 2023 (arXiv 2304.04318): extend-only posets as
      Byzantine-tolerant RDTs
    - pasted [9] arXiv 2504.05398 = Liittschwager et al. 2025,
      "CRDT Emulation, Simulation, and Representation
      Independence": state-based vs op-based equivalence; no Git,
      no Merkle DAGs -> not a source for the semilattice claim,
      but usable for the CvRDT/CmRDT layer split
