# Free Venues (no APC)

- JISA, Journal of Internet Services and Applications (SBC)
    - Qualis A2, JCR 2.4
    - no page limit stated, own LaTeX template
    - fit: P2P, content distribution, security
    - https://journals-sol.sbc.org.br/index.php/jisa
- JBCS, Journal of the Brazilian Computer Society (SBC)
    - Qualis A2
    - no page limit stated, own template, XeLaTeX
- JSys, Journal of Systems Research
    - not classified in Qualis
    - diamond OA, no hard page limit (~12 typical)
    - area "Distributed Consensus"; Solution papers need artifact
    - deadlines: Mar 1, May 1, Aug 1, Oct 1; review in 1.5 months
    - submissions public on OpenReview
    - https://www.jsys.org/cfp
- Ledger (U. Pittsburgh)
    - not classified in Qualis
    - fee $1500 with waiver tiers; 4k-10k words
- J.UCS, Journal of Universal Computer Science
    - Qualis A3, diamond OA
- JCIS, Journal of Communication and Information Systems (SBrT)
    - Qualis A4, free

# Subscription Route (no charge, hybrid OA optional)

- Computer Networks (Elsevier): A1, best fit
    - guide checked 26/11/04: no page limit stated
    - single anonymized; extended conference papers accepted
    - LaTeX double column allowed; `elsarticle` template
    - abstract <= 250 words; 1-7 keywords
    - optional: highlights (3-5, <= 85 chars), graphical abstract
    - figures as separate files (vector PDF ok)
    - tables: no vertical rules (check Table 1)
    - GenAI declaration section before references
    - IF 4.7, CiteScore 8.9
- Journal of Network and Computer Applications (Elsevier): A1
- Future Generation Computer Systems (Elsevier): A1
    - hard cap: 18 pages double column, incl. refs/figures
    - over the cap: returned unreviewed
    - single anonymized; strong blockchain/P2P audience
- Journal of Systems and Software (Elsevier): A1
- Computing (Springer): A1
- IEEE TNSM: A1, overlength charges beyond page cap
- IEEE TDSC: A1, overlength charges beyond page cap
- IEEE TPDS: A1, overlength charges beyond page cap
- IEEE/ACM ToN: A1, overlength charges beyond page cap
- Computer Communications (Elsevier): A2, home area Eng IV
- Peer-to-Peer Networking and Applications (Springer): A2
    - guidelines behind login, unverified
- ACM TOIT: A2, no page charges
- ACM TOCS: A2, very selective
- ACM TOPS: A2, security framing
- Cluster Computing (Springer): A2, weak fit
- Distributed Computing (Springer): A3, theory oriented
- Journal of Information Security and Applications: A3

# Recommendation

- Qualis credit + fit: Computer Networks (A1) -> chosen (26/11/04)
- alternative: FGCS (A1), needs cuts to fit 18 pages
- free + open access + fit: JISA (A2)
- JSys: best community fit, but no Qualis credit
