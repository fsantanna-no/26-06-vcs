# Goal

- replay Wikipedia edit histories on freechains (open chain)
- FIRST corpus where abuse is PRE-moderation and visible:
  vandalism and its revert are both permanent public revisions
- exercises the REVOKE path end-to-end (no other sim does):
  revoked payloads erased, sweep reclaims, metadata stays

# Profiles (4 pages, one chain each)

- FULL history per article (creation -> today), no sampling;
  LIMIT caps the replay, never the fetch
- polemic: Abortion (13,972 revs)
- event: 2023 Turkey-Syria earthquakes (5,861 revs)
- factual: Photosynthesis (5,514 revs)
- vandal-magnet BLP: George W. Bush (drive-by + fast revert;
  distinct from ideological back-and-forth)
- compare: revert rate, editor mix, reclaimed bytes across
  profiles; vs SE post-moderation downvote 3-12%

# Fetch

- per-page full history via Special:Export
    - 1000 revs per request; loop with offset continuation
- store as `sims/data/wiki/<slug>.xml` (ignored)
- add entries + sha256 to `sims/fetch.sh`

# Mapping (wiki-simple.lua)

- revision -> signed post by editor
    - per-editor keys; IP editors -> shared `anon` key
    - payload = revision text (FILE, like se-simple TMP)
- revert -> `revoke 1000` by the reverter
    - detector: revision sha1 == an earlier revision's sha1
    - revoke each intermediate revision (the vandalism)
    - conservative: misses partial reverts (deterministic)
- ts clamp as in se-simple (per-page ts are monotone; clamp
  guards edge cases)
- env knobs: PAGE/LIMIT/WINDOW/SWEEP/ALIAS/BASE/N_REVOKE

# Gated mode (GATED=true, after the open Abortion run)

- init `--dictator=keys/wp`: gated chain, dictator = platform
  (installed build: dictator is ungated and wins forks)
- per-IP keys (not one shared anon): identities born/die/return
- reps < 500 at post time -> `--beg` + dictator `like 1000`
    - first welcome = birth; re-welcome = RESURRECTION
- revoke gated for editors: reverter < 1000 reps -> dictator
  revokes instead; community/dictator ratio = self-funded
  moderation capacity
- resurrection split (revoke effectiveness in replay):
    - vandal res. (was revoked) = revoke worked, positive
    - innocent res. (drained) = false positive, tpd-21 (d)
    - precision = vandal res. / all res.
    - recidivism = resurrected vandals revoked again
- env: GATED, WELCOME policy (always | never-rewelcome-revoked)
- A/B: same page open vs gated (~2x runtime: reps query + begs)
