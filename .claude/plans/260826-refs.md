## Candidates verified (not yet cited)

- `p2p.mst` Auvolat & Taiani, "Merkle Search Trees: Efficient
  State-Based CRDTs in Open Networks", SRDS 2019 (bib added
  2026-08-28; pdfs/mst-auvolat2019-srds.pdf)
    - "pure state-based CRDTs can be efficiently implemented by
      encoding states as specialized Merkle trees, and that this
      approach is well suited to open networks where many nodes
      may join and leave"
    - "we focus in this paper on pure state-based CRDTs that do
      not require either causal broadcast or vector clocks, and to
      their fundamental issue: how to efficiently implement remote
      state merge for large state between nodes that might have
      had no previous interaction"
    - "a CRDT is a set of possible states V with a symmetric join
      operation"; "the only requirements being to implement a
      commutative, associative and idempotent join operator"
    - "This is done without any conditions on the network topology
      as is required by causal broadcast: it results from the fact
      of doing a full state merge at every gossip event"
    - "This is easy to do with any Merkle DAG data structure, as
      introduced by IPFS"
    - targets: Sec.2 P1 SEC sentence (with fed.matrix, p2p.byz);
      CRDT section (state-based vs op-based split; Git DAG as
      CvRDT); SEC proof (no causal broadcast needed); Related Work
      P2P (Bluesky repos are MSTs)
