# Goal

- bound the per-action cost of freechains state
- measured at N=22k (11 MB state, 22.5k actions), one `post`:
    - git read/write: 0.07s (not the problem)
    - lua parse snapshot: 0.13s (O(N))
    - lua serialize snapshot: 0.47s (O(N), worst single term)
    - `advance()` discount scan: 0..3.6s (O(A*N), A = posts in 12h)
    - `ordered()` sort, twice: 0.10s
- disk: full snapshot per action -> O(N^2) loose, gc O(N^2) cumulative
- state never shrinks: 16.8k of 22.5k entries parked in `12-24`

# Baseline

- keep `sims/chat/chat-simple.lua` runs as reference
    - 50k run: `sims/chat/chat-simple-50k.log`
    - post avg, loose/window, sweep time, pack floor
- re-run 10k after each step below, compare

# Step 1: advance() one pass

- `rules.lua:97` inner loop over all actions per `00-12` entry
- sort once, walk backwards accumulating later authors
- O(N log N) total, tiny constant
- expected: removes the busy-hour spikes (up to 3.6s)

# Step 2: bound G.actions

- `12-24` entries wait for the author's daily `earn` slot
    - `rules.lua:137`: one grant per author per 24h
    - queue grows forever with active authors
- options:
    - grant all pending earns at once (drop the per-day cap?)
    - consolidate entries without credit after `fork.time` (7d)
    - keep only a compact index for consolidated entries
- expected: working set = recent window, parse/serialize O(window)

# Step 3: append log instead of snapshot

- state file = sequence of effect lines, one action appends few
    - `act {cid,action,author,time}`
    - `reps {author,delta}`
    - `mature {cid,to}`
- every mutation of `G` emits its line (single mutation point)
- read = fold lines (assignment only, no `advance` replay)
- state at cid = fold of prefix; keep `cid -> offset`
- checkpoint snapshot every K lines, replay tail
- drops `refs/states/*`, `hash-object` per action, `sweep`
- expected: write O(1), disk O(N), no gc

# Step 4: serialize cost (if step 3 not done)

- `table_to_string` sorts keys and concats 11 MB
- cheaper encoder or skip sorting (deterministic order not needed?)

# Won't do

  no floor gain; only memory safety
